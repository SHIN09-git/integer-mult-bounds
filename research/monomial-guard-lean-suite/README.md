## 范围与来源

数学来源为 [PR #6712](https://github.com/CrocSwap/integer-mult-bounds/pull/6712)，固定提交 03caa7f6cb5bd21c834024e9d81f6b43eb325b91。此前 h−Z 形式化固定在 b87752d0291dc8b1df46b9abbccdc739d7c5be57。

三元域结论要求完整仿射族及 bu=1、Wu=0。两端构造覆盖所有非负参数，允许维数变化；形式化统一保留一个零标量辅助坐标。一般域集中定理要求目标总和非零；二元域主子式结论要求守卫族非空且各行归一化，允许重复和相关的守卫。

这是指定操作度量下的定理形式化，不是新的整数乘法指数。官方检查器使用 Lean 同一内核实现。这里的验证记录来自本地运行，不代表外部人工审核、上游验收或 GitHub 托管 Lean 检查已经完成。各包保留原署名与 Apache-2.0 许可，并披露 OpenAI Codex 的实质协助。
